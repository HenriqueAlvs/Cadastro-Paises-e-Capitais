# 🌎 Cadastro de Países e Capitais

Aplicação web desenvolvida para cadastrar, organizar e visualizar países e suas respectivas capitais de maneira simples e intuitiva.

O projeto utiliza **HTML5, CSS3 e JavaScript**, explorando conceitos fundamentais do desenvolvimento Front-End, como manipulação do DOM, arrays, objetos e eventos.

## 📌 Sobre o projeto

O Cadastro de Países e Capitais é um projeto desenvolvido com o objetivo de praticar e consolidar conhecimentos em desenvolvimento web.

A aplicação apresenta uma tabela dinâmica que permite visualizar os países previamente cadastrados e adicionar novos registros por meio de um formulário interativo, sem a necessidade de atualizar a página.

## ✨ Funcionalidades

- 🌎 Exibição de países e suas respectivas capitais.
- 📝 Cadastro de novos países e capitais.
- 📊 Atualização dinâmica da tabela.
- ⚡ Manipulação de elementos HTML através do JavaScript.
- 🎨 Interface moderna, organizada e intuitiva.
- 📱 Layout responsivo para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação da página e dos elementos. |
| CSS3 | Estilização, cores, layout e responsividade. |
| JavaScript | Lógica da aplicação e manipulação dinâmica dos dados. |

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Utilize o formulário para cadastrar novos países e capitais.

## 📚 Conhecimentos aplicados

Durante o desenvolvimento, foram trabalhados conceitos importantes de programação e desenvolvimento Front-End:

- Manipulação do DOM com JavaScript.
- Seleção de elementos HTML com `getElementById()`.
- Manipulação de arrays e objetos.
- Estruturas de repetição com `for`.
- Eventos com `addEventListener()`.
- Prevenção do comportamento padrão de formulários com `preventDefault()`.
- Renderização dinâmica de conteúdo com `innerHTML`.
- Estilização e responsividade com CSS3.
